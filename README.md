# 📊 Power BI Analysis & Visualisations Repository

This repository contains **Power BI Desktop (.pbix) projects** showcasing a range of business intelligence and data analysis work. Each project focuses on real-world data scenarios, transforming raw data into **interactive dashboards, analytical insights, and decision-ready visualisations**.

---

## 🚀 Projects Included

### 1. **Sales Performance Analysis**
A comprehensive performance dashboard exploring sales metrics and team performance.

**Dataset:**

There were 5 data sets used and data was transformed to ensure relevant columns are used for the aim of the analysis.
